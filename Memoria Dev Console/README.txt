MEMORIA DEV CONSOLE v1.4.1

INSTALL
Extract the Memoria Dev Console folder into your FINAL FANTASY IX game folder.
Enable it in the Memoria mod manager, then fully restart FFIX.
Requires Memoria. Built against the installed 2026-11-09 Memoria assemblies.
LC is not required. Moguri is optional; MDC does not override its global tile size.

OPEN AND NAVIGATE
F10: show/hide MDC. Single-click selects; double-click or Enter opens.
Arrow keys navigate. Escape returns one level; from Home it returns to the game.
M: Model Viewer. S: SFX Previewer. F: Rendered Field Viewer. C: Console Color.
White is the default theme; your chosen color is saved automatically.

FILES
Keep Streamingassets, FF9_Data, BattleSceneEditor/Templates and the field-viewer
reference TSVs in FF9_Data/FieldViewer. They contain required runtime code, artwork, catalogs and templates.
Harmony and its license are bundled for Battle Scene Editor camera integration.
Asset Dump and editor output folders are created when needed.
Personal exports, presets, test entrances, aliases and preferences are not included.

IMPORTANT
Keep a normal game save before using experimental warps or development save states.
Field previews approximate scripts and object attachments; validate edits in game.
The Field Background Toolkit edits existing artwork; it does not create field geometry.
World Entrance Creator return exits require manual Hades Workshop field scripting.
Read CHANGELOG.txt and Documentation for tool details.
